Three principals, two hops, left to right. Select any box or arrow to see the endpoint that was called and the claims on the token it produced.

The D3 library did not load from the CDN, so the diagram cannot be drawn. The step list below carries the same information as text.

  • idle, thin outline
  • in progress, dashed
  • issued, thick outline
  • refused by Okta, thick outline
  • no decision reached, dash-dot
  • not attempted, dotted

Refused and no decision are kept apart on purpose. Refused means Okta decided, and decided no. No decision means the call never got that far, so nothing about it can be attributed to Okta.

Every box and arrow also carries its state as text, so nothing here depends on being able to tell the colours apart.
